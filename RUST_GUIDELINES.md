# Rust guidelines

This project follows the universal Rust guidelines at
https://github.com/andrico21/rust-guidelines, vendored byte-for-byte under
`docs/rust-guidelines/` at the commit in `docs/rust-guidelines/PIN`
(checked by `docs/rust-guidelines/SHA256SUMS`).
Read, in this order, before writing or reviewing Rust code here:

1. `docs/rust-guidelines/RUST_GUIDELINES.md` (universal core)
2. `docs/rust-guidelines/overlays/domains/http-services.md`
3. `docs/rust-guidelines/overlays/domains/mcp-servers.md`
4. `docs/rust-guidelines/overlays/projects/keenetic-control-center.md` <- always last

The project overlay lists deviations that are still open. Treat them as tasks, not as
permission.
