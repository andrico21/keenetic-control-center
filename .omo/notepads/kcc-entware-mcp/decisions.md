## [2026-11-21] Todo 3 (e3): Entware read model, ACTUAL API
- Module `kcc_domain::entware` (root `entware.rs`, private `entware/drives.rs`, public `entware/models.rs`; no re-exports, so types live at `kcc_domain::entware::models::*`).
- `DomainId::Entware` (last variant); `entware::DESCRIPTOR` last in `registry()`: read_ops `components`="components list", `media`="show media", `version`="show version" (all Read), `write_ops: &[]`, `required_components: &["usb","storage"]`.
  No `opkg ...` path is registered as a Read op on purpose: kcc-web `advanced::request::reads_only` treats any registry op with `Risk::Read` as a background-safe read, so an `opkg disk` read op would whitelist a Destructive command as a job.
- `pub async fn entware::read_settings(router: &RouterCtx) -> kcc_domain::Result<EntwareSettings>`: `show_rc({"opkg":{}})`, `configuration_tree().get("opkg")`, absent -> `EntwareSettings::default()`.
- `pub async fn entware::read_status(router: &RouterCtx) -> kcc_domain::Result<EntwareStatus>`: reads `show version`, `components list`, `show rc` opkg, `dns::read_configuration`; reads `show media` ONLY when `ndw.components` has both `usb` and `storage` (else drives/initializable empty, possible = NoUsbOrStorage).
- models: `EntwareSettings { disk: Option<String>, initrc: Option<String>, timezone: Option<TimezoneSetting>, chroot: bool, dns_override: bool, extra: BTreeMap<String, Value> }` (Deserialize via private `RawSettings`: each field plain or object keyed by its catalog argument: disk `{"disk","url"}`, initrc `{"path"}`, timezone `"auto"`/`{"auto":true}`/`{"timezone":name}`; flags: bool, any other non-null shape counts as ON (safe reading for chroot)).
  `TimezoneSetting { Auto, Named(String) }`; `Possibility { Possible, NoUsbOrStorage, UnsupportedArch(String) }`; `ComponentPresence { Installed, Available, Missing }` (Installed if in `ndw.components` or listed with installed=true; Available if listed otherwise; else Missing);
  `ArchResolution { Aarch64, MipsAmbiguous, Unknown(String) }` (`arch` "aarch64" / "mips" / other; missing -> Unknown("")) ; Unknown(x) -> Possibility::UnsupportedArch(x);
  `EligibleDrive { media_id: String, disk_arg: String, label: Option<String>, filesystem: String, free_bytes: Option<u64> }` (fs exactly ext2/ext3/ext4; `<label>:/` when label is one CLI word (cli_token::validate) and unique among all media, else `<uuid>:/` from `MediaVolume.extra["uuid"]` (CLI word), else skipped; media without `id` skipped);
  `EntwareStatus { possible, opkg_component, ext_component, settings: EntwareSettings, drives: Vec<EligibleDrive>, initializable: Vec<String> (media ids whose extra["initialize-supported"] has "ext4"), arch, dns_filter_uses_opkg: bool (`dns_proxy` pointer `/filter/engine` == "opkg") }`;
  `Installer { Aarch64, Mipsel, Mips }` + `pub const fn url(self) -> &'static str` (the only place the three URLs appear). Computed types are Serialize only (no Deserialize/extra): only the router-decoded `EntwareSettings` carries `extra`.
- Fake router: `cli_engine/opkg_rules.rs` (`opkg disk|initrc|timezone|chroot|dns-override` identity 2, max words 4/3/3/2/2; `dns-proxy filter engine <e>` identity 3); `projection/entware.rs` projects `show rc`/`show sc` `opkg` in the catalog-argument shape above and `dns-proxy/filter/engine`. `components list` adds `{"name","installed":false}` for `ext`,`opkg` when not installed. Synthetic `Media0` gains `uuid` and `initialize-supported: ["default","ext4","ntfs"]`. Test helper `Fixture::spawn_model(Model)` (5.1) in `crates/kcc-domain/tests/support/mod.rs`.

## [2026-11-21] Todo 24 (e24): API key expiry - actual API
- `kcc_app::api_keys::StoredApiKey.expires_at: Option<u64>` (Unix seconds; `#[serde(default, skip_serializing_if = "Option::is_none")]`, old files load); `StoredApiKey::is_expired(&self, now: u64) -> bool` (`expires_at <= now`).
- `create_api_key(store, actor: &Role, name: String, role: String, created_at: u64, expires_at: Option<u64>) -> Result<CreatedApiKey, ApiKeyError>`; checks, in order: name (`ApiKeyError::InvalidName`), expiry (`ApiKeyError::InvalidExpiry`: must be > created_at and <= created_at + `MAX_KEY_LIFETIME_SECS` = 315_576_000, ten years), then the role grant. Hashing and shown-once unchanged.
- Name rule (moved from kcc-web): `kcc_app::api_keys::is_valid_key_name(&str) -> bool` (1..=`MAX_KEY_NAME_CHARS` (64) of `a-z0-9._-`); every surface goes through `create_api_key`, so no key can be named `oauth:...` (todo 27/31 identity namespaces are safe from keys).
- `expires_after(created_at: u64, lifetime: &str) -> Result<u64, ApiKeyError>` parses a humantime duration (CLI `--expires-in`, Web choices `7d|30d|90d|1y`).
- `api_key_entries` sets the kit's `ApiKeyEntry.expires_at` via `try_with_expiry(humantime RFC 3339)`; an expiry humantime cannot format (year > 9999, hand-edited) drops the entry (fail closed, WARN). The kit checks `exp < Utc::now()` per request (verdict Expired -> 401), no reload needed at expiry.
- `kcc/src/state_watch.rs` `KeySet` now includes `expires_at`, so an expiry edited into `api_keys.json` reloads the transport.
- CLI: `ApiKeyError::{InvalidName, InvalidExpiry}` -> exit 4 (Validation, English Display text like AccountError). `apikey list --json` rows gain `expires_at` (null) and `expired`; human table gains an "Expires" column (Unix seconds, "(expired)"). Audit params of `cli.apikey_create`/`admin.api_key_create` carry `expires_at` only when set.
- New i18n keys: `cli-col-expires`, `cli-key-expired`, `web-admin-key-expires`, `web-admin-key-expired`, `web-admin-key-expires-in`, `web-admin-key-expires-{never,7d,30d,90d,1y}`, `web-admin-error-key-expiry`.
